# 空间猫咖：真实环境猫咪陪伴

需求更新：2026-10-27。当前 Cafe 场景已接入 PICO MR 运行路径，并提供 Unity Editor 桌面预览。Editor 预览用合成背景和模拟表面替代真实透视及空间网格；下述真机效果仍需在 PICO Swan 验证。

## 已确认的体验

用户戴 PICO 头显，看到自己的真实办公室。应用把一只虚拟猫稳定放在真实空间中。用户直接伸手，猫根据真实手的位置自然回应，例如先靠近闻手，再舔手或蹭手。

目标硬件已由 Vibe Lab 项目信息确认为 **Project Swan**，对应 PICO OS 6。采用新的 PICO Unity SDK 作为接入基线；当前查阅到的公共包为 `com.bytedance.pico.xr` 6.1.1，官方仓库修订 `75699354718f13fc9cb7c0a756bb4508913b7acd`。若 Vibe Lab 提供与测试机固件配套的专用 SDK，以配套版本重新核对。公共源码的 README 含旧版本说明，因此包版本以实际 `XR/package.json` 为准。

第一阶段按 PICO XR 的独立透视 MR 体验设计，使用真实头部追踪、手部关节与环境感知，不把 Shared Space 多应用共存列为已实现能力。后续若赛事明确要求 Shared Space，需重新评估 Spatial Adapter 的手部和空间能力限制。

真实办公室是体验背景。应用不再生成虚拟猫咖的墙壁、地板、桌椅和背景天空，也不使用手机式拖动视角。办公室空间信息用于放置、碰撞与遮挡；用于计算的空间网格不作为可见装修显示。

## 第一阶段的完整体验

1. 启动后使用头显的透视画面和头部追踪。
2. 检查空间与手部追踪的可用状态；需要授权时给出用途说明。
3. 在确认的真实地面或桌面上放置一只猫，按真实尺度呈现。
4. 猫待机、呼吸、看向靠近的手。
5. 用户把手缓慢伸到猫鼻前，猫靠近闻手，并在手停留时舔手。
6. 用户摸头或背部，猫眯眼、蹭手或发出呼噜声。
7. 手移开后结束接触动作；失去追踪时停止接触并恢复待机。

主要互动不依赖点击二维按钮。菜单仅用于必要的放置、重新定位和退出操作。

## 行为状态与边界

| 状态 | 进入条件 | 离开条件 |
| --- | --- | --- |
| 等待空间 | 尚无有效的放置表面或头部追踪无效 | 用户完成放置且追踪有效 |
| 待机 | 已放置，无附近有效手掌 | 手进入注意范围 |
| 看手 | 检测到有效手部位置 | 手靠近鼻部，或移开／失去追踪 |
| 闻手 | 手在鼻部前方缓慢靠近 | 稳定停留，或移开／失去追踪 |
| 舔手 | 手在鼻部附近稳定停留 | 手离开、移动过快或失去追踪 |
| 享受抚摸 | 手接触头部或背部并产生有效抚摸运动 | 接触结束或失去追踪 |

初始调参可从鼻部附近 6–10 厘米、停留 0.3–0.5 秒开始；这些是待真机调整的参数，并非已验证的体验数值。手快速经过不立即触发舔手；持续停留也不重复刷取亲密度。舔手动画对准实际接触位置，头部与舌头跟随目标，但猫身仍受已确认的支撑表面约束。

猫只在已确认的可行走区域内移动，桌边与障碍处停下。空间数据有更新时更新相应约束；追踪不可靠时暂停移动。遮挡应让猫能够被真实桌椅合理遮住，具体支持范围须结合目标头显与 SDK 核实。

## 已接入的 MR 路径

- 保留现有猫咪资料、亲密度和存档逻辑，按需要扩展自然互动事件。
- `CafeBootstrap` 只创建一只选中猫咪、MR 状态卡和音频；非 XR Editor 走单独的桌面模拟路径，不生成虚拟猫咖环境。
- PICO Android XR Loader 已加入 XR Plug-in Management；场景配置 PICO Hand Tracking XR Origin、VST Camera Effect 和 PICO Spatial Mesh Building Blocks。
- `PicoMrHandSource` 将 PICO 手掌与食指指尖关节及捏合状态接入 `MrHandSource`；Editor 下仅用鼠标模拟放置输入。
- `MrCatPlacementController` 用头显视线射线命中空间网格碰撞体，在水平表面上放置猫；双手捏合保持约 1.1 秒进入重新放置。
- `MrCatGuideController` 在食指伸直且其余手指收起时从指尖投射引导线；命中有效水平表面后，猫以步态逐步跟随光点。Editor 中按住鼠标模拟该引导。
- `MrCatBrain` 复用看手、闻手和舔手反馈，并检测手指接触猫头／身体表面；抚摸时猫会闭眼、轻蹭并呼噜，同时更新亲密度。
- `MrCompanionHud` 显示选中猫咪资料、亲密度和放置提示，并提供捏合可点按的喂食与玩耍动作入口；互动沿用现有状态、亲密度、猫咪动画和音效逻辑。

此接入尚不表示所有硬件调用都已验证成功。Editor 桌面预览没有真实透视、真实手部追踪、空间锚点保存或真实环境遮挡；真机调试与体验调参仍未完成。

## 仍需验证

- 是否已开启开发者模式并通过 USB 连接本机。

- Swan 固件上 PICO XR 6.1.1 与 Unity 6000.3.27f1 的实际运行兼容性。
- 透视是否正确合成，手部关节是否与 Unity 世界坐标一致，捏合状态是否按预期触发。
- 空间网格碰撞体是否能稳定命中真实桌面／地面，以及猫咪的尺度、方向和遮挡表现。
- APK 构建、安装启动、权限表现、追踪丢失恢复和持续运行性能。

当前工程目标设备为 PICO Swan，Android XR Loader 已写入项目配置。项目没有 Swan 真机运行证据，也没有已验证 APK。

## 代码实现与验证边界

- `Scripts/MR/MrHandSource.cs`：约定世界坐标、米制单位、关节有效性和采样时间；拒绝非有限坐标及过期数据。
- `Scripts/MR/PicoMrHandSource.cs`：从 PICO `PXR_Hand` 读取手掌、食指指尖和捏合状态；设备运行表现尚待 Swan 验证。
- `Scripts/MR/MrCatBrain.cs`：看手、闻手、稳定停留后舔手、抚摸响应，以及追踪丢失或失焦时停止接触动作。
- `Scripts/MR/MrCatPlacementController.cs`：空间网格表面射线放置与重新定位；桌面预览使用模拟表面。
- `Scripts/UI/MrCompanionHud.cs`：显示猫咪资料、亲密度和 MR 放置状态。
- Unity Editor 资源刷新完成，Console 未见 C# 编译错误；PICO Loader 与 Building Blocks 的场景／项目配置已保存。尚未构建 APK，也未在 PICO Swan 上运行。详见 [CLI 接入记录](PICO-CLI-SETUP.md)。

实现参考：Cat-Match-AR 提供猫咪互动和亲密度循环的设计参考；它是较早期的 Android ARCore 工程，本项目没有直接复用其过时 Unity／ARCore 技术栈。PICO 侧使用现有 PICO XR 工程与设备能力。
