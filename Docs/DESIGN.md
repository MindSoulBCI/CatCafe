# 空间猫咖 v0.1 产品与实现规格

## 体验目标

用一个可环顾的温暖猫咖，承载选择猫咪、照顾和建立亲密关系的轻量循环。第一版采用离线 3D 场景，适用于 Android 手机及 Unity Editor 的鼠标预览；Android XR 作为后续目标。

## 画面与结构

- 主场景：开放正面和右侧的猫咖立体微缩场景，原木地板、浅色墙面、鼠尾草绿沙发与吧台、编织地毯、圆桌、盆栽、猫爬架和暖色吊灯。
- 三只原创几何猫咪：橘猫拿铁、灰猫芝麻、奶油猫布丁。三角耳、胡须、眼睛高光、项圈铃铛、条纹与摆尾；通过独立的身体、头部、眼睛和尾巴节点动画。
- 顶栏：品牌、午后／夜晚切换、音效开关。
- 左上资料卡：名字、性格、互动偏好、关系等级，以及亲密、饱腹、精力、心情四项进度。
- 底部互动卡：三只猫选择、当前猫的累计互动次数，抚摸、喂食、逗猫、休息四个操作。
- 反馈：互动后短暂文字提示，爱心上浮、食物和逗猫球按动作显示。
- 辅助：操作说明与重置视角。

背景使用浅灰绿，界面以米白、深绿、低饱和粉棕为主。uGUI 使用打包的 Noto Sans CJK SC；按钮和卡片使用代码生成的圆角 Sprite。横屏参考分辨率 1440 × 900，竖屏 900 × 1440，内容布局在 `Screen.safeArea` 内。

## 数据与交互规则

| 数据 | 初始值 | 边界与变化 |
| --- | --- | --- |
| 亲密 | 20 | 0–100；抚摸 +3，喂食 +4，玩耍 +5；偏好动作乘 1.6 |
| 饱腹 | 65 | 0–100；喂食 +23；在线每秒 -0.035；≥94 禁止再喂食 |
| 精力 | 80 | 0–100；玩耍 -14，休息 +22；在线每秒 +0.045；<15 禁止玩耍 |
| 心情 | 70 | 0–100；抚摸 +6，喂食 +4，玩耍 +13，休息 +3；在线每秒 -0.018 |
| 互动次数 | 0 | 每次被接受的动作 +1 |

关系等级：亲密度 <50 为“初见的温柔”，50–79 为“信任的朋友”，≥80 为“最亲密的伙伴”。亲密度达到 100 后仍可互动，数值不继续增长。

普通动作冷却 1.2 秒，玩耍冷却 2.8 秒；冷却应用于整个会话。选择其他猫不会绕过冷却。休息动画约 3 秒；状态收益在动作接受时一次结算。

选中其他猫只切换目标，再点同一只猫触发抚摸。操作 UI 不触发场景选中。两指缩放会取消单指点击识别。抚摸动作会眯眼并轻摆头，喂食会低头，玩耍会小幅跳跃，休息会压低身体。

## 实现边界

`CafeSession` 是动作与状态的唯一入口；`CafeRepository` 管理 JSON、本地备份和异常恢复；场景、UI、音效只订阅状态和动作事件。`SpatialCatInteractor` 把射线、指尖位置和选中对象的动作转给同一会话。现有鼠标／触控射线已走这条桥接路径。

`CafeBootstrap` 负责组装；`SceneShapes` 缓存材质并管理生成网格；静态房间在猫咪创建前批处理，猫咪节点继续独立动画。当前目标帧率设置为 60，不构成设备实测性能承诺。
